#  Wine Quality Analysis Using NumPy

## Overview

This project demonstrates efficient data manipulation and exploratory data analysis (EDA) using **NumPy** on the Wine Quality dataset.

Rather than relying on Pandas for analysis, this project focuses on solving practical data analysis problems using NumPy arrays, Boolean masking, array indexing, aggregation functions, sorting, and statistical calculations.

The project is part of my Data Science portfolio and represents my first complete NumPy-based exploratory analysis.



## Objectives

The objectives of this project are to:

- Practice efficient data manipulation using NumPy
- Develop problem-solving skills using real-world datasets
- Explore the relationship between chemical properties and wine quality
- Build a strong foundation before progressing to Pandas and Machine Learning

## Investigations Performed

The following characteristics were investigated to determine their association with wine quality:

- Alcohol
- Volatile Acidity
- Citric Acid
- Sulphates
- pH
- Density



## Summary of Findings

| Variable | Association with Wine Quality |
|-----------|------------------------------|
| Alcohol | Positive |
| Volatile Acidity | Negative |
| Citric Acid | Positive |
| Sulphates | Positive |
| pH | Little to No Apparent Association |
| Density | Little to No Apparent Association |



## Key Takeaways

The analysis suggests that wines with higher quality scores generally have:

- Higher alcohol content
- Higher sulphates content
- Higher citric acid content
- Lower volatile acidity

On the other hand, pH and density showed little difference between higher-quality and lower-quality wines based on their average values.

These findings indicate associations within this dataset and should not be interpreted as causal relationships.
